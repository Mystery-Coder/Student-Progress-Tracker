\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Cryptocurrency markets are highly dynamic and are significantly influenced by public sentiment expressed on online platforms. Social media forums such as Reddit contain vast amounts of user-generated content related to cryptocurrency discussions, opinions, and market trends. Efficient storage, organization, and analysis of this unstructured data require a well-designed database system.

This project presents the design and implementation of a Crypto Opinion Extraction and Question Answering System with a strong emphasis on database management concepts. The system collects cryptocurrency-related posts and comments from Reddit and stores them using a structured relational database supported by NoSQL storage for handling semi-structured and large-scale data. Core DBMS concepts such as Entity Relationship modeling, relational schema design, normalization, and data flow diagrams are applied to ensure data consistency, scalability, and efficient retrieval.

The proposed system enables effective management of social media data and supports opinion extraction and question answering by organizing textual data in a form suitable for analytical processing. This project demonstrates the integration of traditional relational databases with NoSQL databases and highlights the practical application of DBMS principles in modern data-driven applications.
