\chapter{Introduction}

In recent years, cryptocurrencies have emerged as a significant component of the global financial ecosystem. Unlike traditional financial assets, cryptocurrencies are highly volatile and are strongly influenced by public opinion, news, and social media discussions. Platforms such as Reddit play a crucial role in shaping investor sentiment, as users actively discuss market trends, predictions, and opinions in real time. Extracting meaningful insights from such large-scale textual data is challenging due to its unstructured nature, high volume, and rapid updates.

The Crypto Opinion Extraction and Question Answering System aims to address this challenge by designing a database-driven system capable of storing, managing, and analyzing cryptocurrency-related discussions. The project focuses on collecting user posts and comments from Reddit, organizing them efficiently using database management techniques, and enabling opinion extraction and question answering using Natural Language Processing (NLP) concepts.

This project emphasizes the application of Database Management Systems (DBMS) concepts such as entity-relationship modeling, relational schema design, normalization, and integration with NoSQL databases for handling semi-structured and real-time data. By combining structured relational databases with NoSQL storage, the system ensures scalability, flexibility, and efficient data retrieval.

The proposed system serves as an academic demonstration of how modern applications can integrate traditional DBMS principles with emerging data-driven techniques to analyze social media data and extract useful insights related to cryptocurrency trends.

% ------------------------------------------------------------
\section{Objectives}
% ------------------------------------------------------------

The main objectives of this project are:

\begin{itemize}
    \item To design and implement a database system for storing cryptocurrency-related discussions collected from Reddit.
    \item To model the system using an Entity Relationship (ER) diagram and convert it into an optimized relational schema.
    \item To apply normalization techniques to reduce redundancy and maintain data consistency.
    \item To implement functional requirements such as storing posts, comments, users, and subreddit information.
    \item To support opinion extraction and question answering by structuring data in a form suitable for analytical processing.
    \item To demonstrate the use of both Relational Databases and NoSQL databases for handling structured and semi-structured data.
\end{itemize}

% ------------------------------------------------------------
\section{Scope}
% ------------------------------------------------------------

The scope of this project is limited to academic purposes and focuses on the database design and data management aspects of the system. The project includes:

\begin{enumerate}
    \item Collection and storage of cryptocurrency-related posts and comments from selected Reddit subreddits.
    \item Design of ER diagrams, relational schemas, and normalized database tables.
    \item Implementation of functional requirements using a relational DBMS.
    \item Use of NoSQL databases for handling large-scale or live data where schema flexibility is required.
\end{enumerate}

The project does not aim to provide real-time financial predictions or investment advice. Advanced machine learning model optimization and deployment are outside the scope of this lab project. However, the system is designed in such a way that it can be extended in the future to support advanced analytics, real-time dashboards, and large-scale deployment.
