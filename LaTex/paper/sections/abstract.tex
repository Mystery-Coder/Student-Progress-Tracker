\begin{abstract}
Accurate and transparent financial prediction systems are critical for informed decision-making in lending, real estate, and investment domains. However, many existing solutions rely on black-box models with limited interpretability and lack support for multiple financial use cases within a unified framework. This paper presents an explainable machine learning--based financial decision-support system that addresses loan approval prediction, property price estimation, and stock price forecasting. The system employs domain-specific models, including logistic regression for credit risk assessment, random forest regression for property valuation, and a feed-forward neural network for stock price prediction. Robust data preprocessing and feature engineering techniques are applied to ensure consistent and reliable performance across diverse datasets. To enhance transparency, the system integrates explainable artificial intelligence methods, using LIME for loan predictions and SHAP for property and stock predictions. An interactive web-based dashboard enables real-time input, visualization, and explanation of results. Experimental evaluation demonstrates that the proposed system achieves accurate predictions while significantly improving interpretability and practical usability.
\end{abstract}
